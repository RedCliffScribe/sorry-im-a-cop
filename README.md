# 对唔住，我系差人

### Sorry, I'm a Cop

一款以 1980—1996 年香港为舞台、由玩家选择与人工智能共同推动的本地优先互动叙事 RPG。

[在线游玩](https://simc.pages.dev/) · [English](README.en.md) · **v2.0.4**

</div>

## 一座会继续生活的香港

你可以从警察、社团成员或普通市民开始人生。案件、人物、关系、新闻、机构与城市压力会在结构化状态中持续发展；人工智能负责理解行动与形成叙事，本地运行时负责保存事实、校验写回、结算判定并让后续回合承接已经发生的事。

这不是固定任务树，也不把香港生活压缩成单纯的警务流程。玩家可以办案、工作、经营关系、处理资产、介入城市事件，也可以离开眼前的冲突，让其他人物和组织继续行动。

## 当前版本

v2.0.4 公开源码包含：

- **三种起源与持续身份**：警察、社团、市民拥有不同开局、权限、工作节奏和社会关系，身份变化不会清空既有生活。
- **长存档世界状态**：人物志、NPC 记忆、人脉与缘分、案件、事项、新闻、资产、收支、天气、经验、口碑及组织演化均由本地状态承接。
- **本地判定与写回保护**：判定、成长、案件归属、关系证据和长期剧情弧经过本地校验，模型格式异常不会轻易破坏整个回合。
- **官方剧情 DLC《都市怪谈》**：可在新游戏选择，也可安全加入兼容的香港 1988 旧存档；长期故事会保持唯一事件身份并支持暂停、恢复和持续推进。
- **AVG 正文演出**：支持旁白、对白、立绘、场景、回合重播与原正文切换。未安装资源包时自动使用原正文，不影响存档。
- **自定义内容与创意工坊**：支持自定义人物、事件与内容项目，并提供公开预设的浏览、校验和导入链路。
- **多供应商模型与文生图**：主叙事、修复、记忆、嵌入、后台演化和图片生成可以分别绑定兼容的服务档案。
- **桌面与移动端适配**：主要面板、长列表、弹窗、开局档案与设置页面均提供响应式布局和区域滚动。

完整的玩家可见变更记录可在游戏首页打开“更新日志”查看。

## 在线游玩

打开 [https://simc.pages.dev/](https://simc.pages.dev/) 即可进入游戏。首次使用需要在设置中填写你自行选择的模型服务；项目不附带公共 API Key。

存档、API 档案和运行状态默认保存在当前浏览器的本地数据库中。更换浏览器、设备或清理站点数据前，请先从存档界面导出备份。

## 本地运行

需要 Node.js `^20.19.0` 或 `>=22.12.0` 与 npm：

```powershell
git clone https://github.com/RedCliffScribe/sorry-im-a-cop.git
cd sorry-im-a-cop
npm ci
npm run dev
```

生产构建：

```powershell
npm run build
npm run preview
```

## AVG 美术资源

AVG 演出使用独立资源包，避免把大体积美术文件并入网页源码仓库。资源包可从 [SourceForge 发布目录](https://sourceforge.net/projects/sorry-im-a-cop-v2/files/hk1988-avg-resource-pack/1.2.0/) 下载，然后在游戏设置的“AVG 演出资源”中导入。

本仓库不包含 AVG 资源包、候选图、生产过程素材或原始美术工程文件。仓库中既有的少量内置界面与游戏运行素材仅用于保证源码可以正常构建，并受下方内容资产许可证约束。

## 公开仓库边界

这是面向玩家和二次开发者的可发布源码快照。以下内容不会进入公开仓库：

- 内部规划、施工、验收与开发过程文档；
- API Key、API 配置导出、玩家存档和诊断原文；
- 原始模型响应、临时测试输出、`dist`、`output`；
- 外置美术包、未采用候选图和美术生产目录。

## 本地数据、API 与隐私

- 模型请求由浏览器直接发送给玩家选择的第三方服务，不经过开发者运营的 AI 中转服务器。
- 导出的 API 设置可能包含明文密钥，只应保存在本机或可信的私有备份中。
- 可选运营统计只记录有限的匿名运行指标，不保存原始 IP、API 密钥、剧情、玩家输入、存档、提示词或模型响应正文。
- 本地开发默认不发送运营统计；生产环境中的在线统计采用低频、合并后的活跃状态上报。
